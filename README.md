# AchillesTendon

Code for A Computational Pipeline for the Analysis of Wearable Sensor Data for Achilles Tendinopathy.  All code is structured as python notebooks that can be recreated with the data used in the study.
John Drazan is the owner of all data used in this study: jdrazan@fairfield.edu

analysis ML manuscript updated2.ipynb contains the process to parse the step data

Pipeline_example(1).ipynb is an example of the machine learning pipeline used to generate the results found in this study

Folders labelled LSTM, RF, and SVM were used to develop specific models for the 3-class, 6-class, and 18-class models and are deprecated.
